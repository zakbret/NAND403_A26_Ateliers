Outil de transfert de pivot

Description

Cet outil permet de transférer le point de pivot d'un objet vers un ou
plusieurs autres objets. Sélectionnez d'abord l'objet source (celui dont
vous voulez copier le pivot), puis les objets cibles, et lancez le script :
tous les objets cibles adopteront la position de pivot de la source. Pratique
pour faire pivoter plusieurs objets autour d'un même point de référence.

Utilisation : sélectionnez la source en premier, puis les cibles, et
cliquez sur l'icône de l'outil.

---

Installation du script

1. Ouvrir Maya.
2. Aller dans le menu Windows > General Editors > Script Editor
3. Dans le Script Editor, aller dans la section Python et coller le
   contenu du fichier atelier_8.py
4. Cliquer sur l'engrenage dans la section Shelf
5. Choisir New Shelf et le nommer Script
6. Dans le Script Editor, sélectionner tout le code, puis le glisser-déposer
   dans le nouveau shelf avec le bouton du milieu de la souris (molette)

   Une icône est maintenant créée dans le shelf Script

---

Changement de l'icône

1. Clic droit sur l'icône > Edit
2. Aller dans la section Shelves
3. Cliquer sur le dossier à côté de Icon Name
4. Sélectionner l'image fournie avec ce script : icone_script_gizmo.webp
5. Cliquer sur Save All Shelves.
